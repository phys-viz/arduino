How Zio Arduino works

Examples opens a starter sketch. You’ll be asked before replacing your code.

Editing: Enter continues indentation; Tab indents selected lines and Shift+Tab unindents. Ctrl+Z undoes typing or automatic edits; Ctrl+Shift+Z or Ctrl+Y redoes them (Command on Mac). Undo history lasts for this session.

Sending serial messages: choose Newline, No line ending, Carriage return, or Both CR + LF beside Send.

Zio Arduino is a browser-based tool for writing, compiling, and uploading code to an Arduino Uno or Nano — no software to install, no account needed. It also includes a Serial Monitor and live data plotter for watching what your board is doing while it runs.

1. Write your code, then click Compile. This turns it into a program the board can run — it doesn't touch the board yet.

2. Click Upload. The first time you connect a board, Chrome will ask you to pick it from a list — after that, it's remembered and won't ask again.

If an upload fails, check the reported error and selected board/bootloader before retrying.

Serial Monitor shows whatever your sketch prints while it's running, and lets you type things back to it. It needs its own Connect step, and it can't be open at the same time as an Upload — only one thing can talk to the board at once.

The monitor keeps the latest 2,000 text lines. The plot displays 300 samples; Save CSV exports the full capture, up to 100,000 samples. Missing measurements remain blank. At the capture limit, save and Clear to continue.

Save .ino / Load .ino let you save your code as a real file (to Drive, Downloads, wherever) or bring one back in later.
