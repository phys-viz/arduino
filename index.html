How Sketchbench works

1. Write your code, then click Compile. This turns it into a program the board can run — it doesn't touch the board yet.

2. Click Upload. The first time you connect a board, Chrome will ask you to pick it from a list — after that, it's remembered and won't ask again.

If an upload fails partway through, that's usually just a momentary hiccup with the USB connection — click Upload again and it typically goes through.

Serial Monitor shows whatever your sketch prints while it's running, and lets you type things back to it. It needs its own Connect step, and it can't be open at the same time as an Upload — only one thing can talk to the board at once.

Save .ino / Load .ino let you save your code as a real file (to Drive, Downloads, wherever) or bring one back in later.
